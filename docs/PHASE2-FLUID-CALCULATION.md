# Phase 2：CRRT 液体量计算规则

最后核对：2026-09-03

## 目标

本阶段只完成最基础、可追溯的液体量换算：

- 体重 × 目标治疗剂量 → 目标总流出液量
- 净超滤单独列出
- 根据 CVVH / CVVHD / CVVHDF 模式拆分置换液与透析液
- CVVHDF 不内置“指南唯一比例”，由医生选择 1:1 或自定义比例
- SCUF 暂不套用溶质清除剂量公式

## 当前公式

### 1. 目标总流出液量

```text
目标总流出液量（mL/h） = 体重（kg） × 目标治疗剂量（mL/kg/h）
```

CRRT 剂量通常以单位体重、单位时间的总流出液量表示。

### 2. 扣除净超滤后用于置换液 / 透析液的流量

```text
置换液 + 透析液（mL/h） = 目标总流出液量 - 净超滤速度
```

净超滤（patient net fluid removal）与溶质清除处方在界面中分开显示，避免把“脱水速度”和“治疗剂量”混为同一个参数。

### 3. 模式分配

- CVVH：剩余流量全部作为置换液
- CVVHD：剩余流量全部作为透析液
- CVVHDF：需要指定置换液 / 透析液比例
  - 可选 1:1
  - 可自定义百分比，二者合计必须为 100%
- SCUF：Phase 2 不自动计算

## 前稀释 / 后稀释

Phase 2 先记录稀释方式，不自动做前稀释有效清除校正。

原因：前稀释会降低滤器入口溶质浓度，因此“处方流出液量”不能完全等同于实际溶质清除。该校正后续单独补充，避免当前版本为了少数复杂场景把主流程做得过重。

## 医学依据

### 主来源：2026 中国正式指南

《中国连续肾脏替代治疗处方液体应用临床实践指南（2026版）》

- 制定者：中国医疗保健国际交流促进会重症医学分会、中国重症血液净化协作组
- 期刊：中华医学杂志，2026，106(15):1409-1424
- DOI：10.3760/cma.j.cn112137-20260108-00083
- 正式发表日期：2026-04-21

与 Phase 2 直接相关的要点：

- 指南推荐 CRRT 优先采用以透析或透析为主的模式（CVVHD / CVVHDF），而非单纯 CVVH。
- 指南要求根据血中目标溶质浓度动态调整置换液 / 透析液剂量。
- 指南给出的临床示例中，病情稳定时治疗剂量可回落至 25 mL/(kg·h)，高钾或高代谢状态时可阶段性提高。
- 指南没有给出所有 CVVHDF 患者统一固定的“置换液 : 透析液”比例，因此程序不把某个比例伪装成指南标准答案。

### 补充来源：KDIGO 2026 AKI/AKD Public Review Draft

KDIGO 2026 AKI/AKD 指南公开评审稿提出成人 CRRT 实际递送 effluent volume 20–25 mL/kg/h。

注意：截至 2026-09-03，该版本仍属于 Public Review Draft，不作为本项目唯一正式依据，仅用于补充核对。

## 当前边界

Phase 2 不处理：

- 枸橼酸、肝素计算
- 葡萄糖酸钙
- NaHCO3
- KCl
- 前稀释有效剂量精确校正
- 高 BMI 的理想 / 校正体重选择
- 滤器停机时间造成的 delivered dose 修正

这些后续按 Phase 3–5 逐块接入。
