# V1 离线版发布检查清单

适用对象：通过 U 盘复制到医院内网电脑、直接双击 `index.html` 使用的 CRRT / CBP 处方参数计算器。

## 开发机发布前

- [ ] `git pull` 已同步最新代码
- [ ] `npm install` 已完成
- [ ] `npm test` 全部通过
- [ ] `npm run build` 构建成功
- [ ] `dist/index.html` 已生成
- [ ] 直接双击 `dist/index.html` 可以正常打开
- [ ] 数字输入框可直接键盘输入，不出现浏览器上下微调箭头
- [ ] Stepper 可以完整走完：基础信息 → 治疗设置 → 抗凝 → 电解质 / 缓冲液 → 结果
- [ ] 一键复制在离线 `file://` 场景可用
- [ ] 清空重算可用

## 主流程回归

至少人工核对以下路径：

- [ ] CVVH
- [ ] CVVHD
- [ ] CVVHDF 1:1
- [ ] CVVHDF 自定义比例
- [ ] 无抗凝
- [ ] 4% 枸橼酸钠
- [ ] 普通肝素
- [ ] RCA + 10% 葡萄糖酸钙
- [ ] NaHCO₃ 换算
- [ ] KCl 换算
- [ ] 高钾血症 `0–2 mmol/L` 范围提醒
- [ ] 错误输入能触发 Error 并阻止复制正式摘要
- [ ] Warning / Info 可进入“需核对”摘要

## 科室正式使用前

- [ ] ICU / 肾脏相关负责人核对当前主流程是否符合本科室实际开方习惯
- [ ] 确认普通肝素首剂采用 2023 共识 `5–15 IU/kg`，或决定切换至其他院内方案
- [ ] 核对本院实际使用的枸橼酸、葡萄糖酸钙、NaHCO₃、KCl 制剂规格
- [ ] 用 3–5 份已脱敏的既往真实处方进行人工反算对照
- [ ] 确认计算器仅用于参数换算和校验，不自动替代临床治疗决策

## U 盘交付

正式使用电脑只需要复制：

```text
dist/index.html
```

建议交付时重命名为带版本号的文件，例如：

```text
CRRT-Calculator-v1.0-rc1.html
```

旧版建议保留一份，避免覆盖后无法回退。
