# Phase 3：CRRT 抗凝计算

本阶段只实现两条常用路径：

- RCA（regional citrate anticoagulation，局部枸橼酸抗凝）
- UFH（unfractionated heparin，普通肝素）

目标是提供**初始换算值 / 指南范围**，治疗中仍需根据监测动态调整。

## 1. RCA：4% 枸橼酸钠

### 1.1 输入

- 血流量 `Qb`：mL/min
- 枸橼酸制剂浓度：mmol/L
- 可选：目标体外血液枸橼酸浓度：mmol/L

4% 枸橼酸钠按约 `136 mmol/L` 枸橼酸根用于换算。

### 1.2 公式

```text
枸橼酸泵速（mL/h）
= 血流量（mL/min） × 60 × 目标体外枸橼酸浓度（mmol/L）
  ÷ 枸橼酸制剂浓度（mmol/L）
```

若未填写目标浓度，页面显示传统 `3–4 mmol/L` 对应的泵速范围，不擅自选择一个固定值。

例如：

```text
Qb = 130 mL/min
4% 枸橼酸钠 ≈ 136 mmol/L

3 mmol/L → 172.1 mL/h
4 mmol/L → 229.4 mL/h
```

### 1.3 最新指南监测目标

《中国连续肾脏替代治疗处方液体应用临床实践指南（2026版）》推荐：

- RCA 时滤器后 iCa（ionized calcium，离子钙）初始目标：`0.2–0.3 mmol/L`
- 肝功能衰竭、休克等枸橼酸蓄积高风险患者：可调整为 `0.3–0.4 mmol/L`
- 4% 枸橼酸盐抗凝剂与 0.5% 枸橼酸盐置换液均可使用，目前无明确证据证明哪种更优

因此，计算器把泵速定义为**初始换算**，后续必须按滤器后 iCa 动态调整。

### 1.4 0.5% 枸橼酸盐置换液

2026版指南允许使用，但其属于整套处方液方案，不能简单复用4%枸橼酸钠独立泵入公式。

Phase 3 仅识别该选项并提示“暂不自动换算”，避免给出伪精确结果。

## 2. 普通肝素

采用《抗凝技术在危重症肾脏替代治疗应用的中国专家共识（2023年版）》中的 CRRT 普通肝素范围：

```text
首剂：5–15 IU/kg 静注
维持：5–10 IU/kg/h
```

计算器根据体重输出 IU 范围：

```text
首剂范围 = 体重 × 5 ～ 体重 × 15 IU
维持范围 = 体重 × 5 ～ 体重 × 10 IU/h
```

如填写泵内实际浓度（IU/mL），继续换算：

```text
泵速（mL/h） = 维持剂量（IU/h） ÷ 泵内浓度（IU/mL）
```

例如 70 kg，肝素配置浓度 500 IU/mL：

```text
首剂：350–1050 IU
维持：350–700 IU/h
泵速：0.70–1.40 mL/h
```

### 2.1 监测

2023年中国专家共识：

- APTT（activated partial thromboplastin time，活化部分凝血活酶时间）：`45–60 s`
- 或抗 Xa 活性：`0.3–0.6 IU/mL`

计算器只显示目标范围，不根据单次化验值自动修改剂量。

## 4. 当前边界

Phase 3 暂不实现：

- 葡萄糖酸钙补充量：Phase 4
- NaHCO₃ / KCl：Phase 4
- ACD-A 自动换算
- 0.5% 枸橼酸盐置换液完整处方方案
- 肝素根据 APTT 自动滴定
- 低分子肝素、阿加曲班等其他抗凝方案

这些均保留扩展入口，不影响现有基础架构。
