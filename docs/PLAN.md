# CRRT Calculator 开发计划

当前状态：**V1 主流程完成，版本 `1.0.0-rc.1`。**

目标已经从“先把 90% 常用流程跑通”推进到可离线交付的 Release Candidate。后续新增内容优先改配置、公式、校验和来源登记，不重做页面骨架。

## Phase 0：Demo 骨架（已完成）

- Stepper 分步流程
- 配置驱动字段
- 动态显示分支
- “其他”自由输入
- 实时结果摘要
- PC / 手机响应式布局

## Phase 1：核心输入模型（已完成）

- 体重
- CRRT / CBP 模式
- 目标治疗剂量
- 血流量
- 置换液 / 透析液分配
- 抗凝方式
- 枸橼酸、肝素、葡萄糖酸钙、NaHCO₃、KCl 制剂规格
- 必填 / 选填逻辑收拢

## Phase 2：液体量（已完成）

- 体重 × 目标治疗剂量 → 目标总流出液量
- 净超滤独立录入
- CVVH / CVVHD 自动分配
- CVVHDF 1:1 / 自定义比例
- 前 / 后稀释记录
- SCUF 不误套溶质清除公式

## Phase 3：抗凝（已完成）

- 4% 枸橼酸钠初始泵速换算
- 传统 3–4 mmol/L 初始体外枸橼酸范围
- 滤器后 iCa 目标提示
- 普通肝素首剂 / 维持剂量范围
- 输入肝素泵内浓度后换算 mL/h
- APTT / 抗 Xa 监测提示

## Phase 4：电解质 / 缓冲液（已完成主流程）

- RCA + 葡萄糖酸钙
- NaHCO₃ 配液 / 泵速换算
- KCl 配液量换算
- 高钾血症处方液钾范围提示
- 医生设定目标浓度，计算器负责换算

## Phase 5：临床规则与防呆（已完成主流程）

- Error / Warning / Info 三级校验
- 单位和数值合法性
- 净超滤与目标总流出液关系
- CVVHDF 比例校验
- 隐藏旧分支不继续误报
- RCA / NaHCO₃ / KCl 分支依赖检查
- 明显危险或不支持组合提醒
- 数字输入框隐藏浏览器微调箭头

## Phase 6：结果页（已完成）

- 最终“结果”步骤
- 集中展示液体量、抗凝、电解质 / 缓冲液
- 纯文本处方参数摘要
- Warning / Info 自动写入“需核对”
- Error 阻止复制正式摘要
- 返回修改 / 清空重算
- `file://` 离线复制兼容

## Phase 7：医学来源管理（V1 基础版已完成）

已建立：

- `docs/CLINICAL-SOURCES.md`
- 主要正式指南 / 共识名称、年份、DOI、发布状态
- KDIGO 2026 AKI / AKD Public Review Draft 状态说明
- 普通肝素 2022 指南 vs 2023 共识首剂冲突登记
- 公式更新流程

V1 正式科室上线前仍需：

- ICU / 肾脏相关负责人确认普通肝素首剂采用哪套院内方案
- 核对本院实际制剂规格
- 使用脱敏真实既往处方做人工反算

## Phase 8：扩展模块（暂缓）

按真实科室反馈再决定是否开发：

- TPE（Therapeutic Plasma Exchange，治疗性血浆置换）
- 特殊滤器 / 特殊机型
- 特殊抗凝方案
- 科室模板
- 打印 / 导出
- 更多院内部署形式

这些扩展不影响当前 V1 基础架构。

## 交付形态（已实现）

开发源码保持模块化；正式构建使用 `vite-plugin-singlefile`，输出：

```text
dist/index.html
```

医院电脑只需要这一个文件，双击即可离线使用，不需要 Node.js、npm 或互联网。

发布前按 `docs/RELEASE-CHECKLIST.md` 执行。

## 开发原则

- 主流程优先，边缘场景后补
- UI、临床配置、计算公式、校验、输出彼此独立
- 新增常用选项优先改配置，不破坏页面骨架
- 所有“其他”分支保留自由输入
- 所有计算值可追溯来源
- 工具负责参数换算和校验，不自动替代临床治疗决策
