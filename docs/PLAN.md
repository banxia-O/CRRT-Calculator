# CRRT Calculator 开发计划

目标：先把 90% 常用流程跑通，再逐步补医学规则与边角情况；页面骨架保持稳定，后续优先改配置、公式和校验层。

## Phase 0：当前 Demo 骨架（已完成）

- Stepper 分步流程
- 配置驱动字段
- 动态显示分支
- 每个选择模块支持“其他”自由输入
- 实时处方摘要
- PC / 手机响应式布局

## Phase 1：计算器核心输入模型

先把真正参与计算的字段收拢：

- 体重
- CRRT / CBP 模式
- 目标治疗剂量（mL/kg/h）
- 血流量（mL/min）
- 置换液 / 透析液分配方式
- 抗凝方式
- 制剂规格 / 浓度（枸橼酸、肝素、葡萄糖酸钙、NaHCO3、KCl）

要求：

- 选项全部配置化
- 常用选项之外统一保留“其他”
- 单位作为字段元数据维护
- 页面不写死医学逻辑

## Phase 2：液体量计算模块

优先完成最核心路径：

1. 体重 × 目标治疗剂量 → 总治疗流量
2. 按治疗模式拆分置换液 / 透析液
3. 前稀释 / 后稀释作为独立配置
4. 净超滤与治疗剂量分开显示

产物：

- `src/calculators/fluid.ts`
- 单元测试
- 结果摘要展示

## Phase 3：抗凝模块

分两条常用路径：

### 枸橼酸

输入：
- 血流量
- 枸橼酸制剂浓度
- 目标枸橼酸负荷

输出：
- 初始枸橼酸泵速
- 与钙补充相关的后续字段

### 肝素

输入：
- 体重
- 是否需要负荷剂量
- 制剂浓度

输出：
- 负荷剂量
- 维持剂量 / 速度

产物：

- `src/calculators/anticoagulation.ts`
- 公式来源与版本记录
- 单元测试

## Phase 4：电解质与缓冲液模块

依次接入：

- 葡萄糖酸钙
- NaHCO3（碳酸氢钠）
- KCl（氯化钾）

原则：

- 仅在指南存在明确换算关系时自动计算
- 需要实验室指标动态调整的项目，不伪装成固定答案
- 必要时输出“建议范围 / 需结合化验调整”，而不是单一值

## Phase 5：临床规则与校验层

新增 `src/validation/`：

- 必填字段检查
- 单位 / 数值范围检查
- 模式与液体字段的相容性检查
- 抗凝相关提示
- 结果异常提示

提示只做安全校验，不替代医生做适应证判断。

## Phase 6：结果页

输出结构：

- 患者基础参数
- 治疗模式
- 总治疗剂量
- 置换液速度
- 透析液速度
- 净超滤
- 抗凝剂量 / 速度
- 钙、NaHCO3、KCl 相关结果
- 计算依据 / 来源版本

支持：

- 一键复制文本
- 清空 / 重新计算
- 后续可扩展打印模板

## Phase 7：医学核对与来源管理

每条公式记录：

- 来源指南 / 共识
- 发布年份
- 页码 / 章节
- 公式或推荐范围
- 是否正式发布
- 最近核对日期

优先级：

1. 最新正式发布的中国 CRRT / 血液净化指南或共识
2. KDIGO 正式指南
3. 最新指南草案只作补充，不作为唯一正式依据

## Phase 8：扩展模块（后做）

- TPE（治疗性血浆置换）
- 特殊滤器 / 特殊机型
- 特殊抗凝方案
- 科室模板
- 打印 / 导出
- 院内部署

这些都不影响前面基础架构。

## 开发原则

- 先跑通主流程，再补 1% 边缘情形
- UI、临床配置、公式、校验相互独立
- 新增常用选项优先改配置，不改页面骨架
- 所有“其他”分支必须可自由输入
- 所有计算值必须能追溯来源
- 计算器输出辅助参数，不自动替代临床判断
