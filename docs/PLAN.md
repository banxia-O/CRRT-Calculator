# CRRT Calculator 开发计划

目标：先把 90% 常用流程跑通，再逐步补医学规则与边角情况；页面骨架保持稳定，后续优先改配置、公式和校验层。

## Phase 0：Demo 骨架（已完成）

- Stepper 分步流程
- 配置驱动字段
- 动态显示分支
- 每个选择模块支持“其他”自由输入
- 实时处方摘要
- PC / 手机响应式布局

## Phase 1：计算器核心输入模型（已完成）

已收拢真正参与计算的字段：

- 体重
- CRRT / CBP 模式
- 目标治疗剂量（mL/kg/h）
- 血流量（mL/min）
- 置换液 / 透析液分配方式
- 抗凝方式
- 制剂规格 / 浓度（枸橼酸、肝素、葡萄糖酸钙、NaHCO3、KCl）

实现：

- 选项配置化
- 常用选项之外统一保留“其他”
- 单位作为字段元数据维护
- 页面不写死医学逻辑

## Phase 2：液体量计算模块（已完成）

已实现：

1. 体重 × 目标治疗剂量 → 目标总流出液量
2. 净超滤独立录入与显示
3. CVVH：自动计算置换液速度
4. CVVHD：自动计算透析液速度
5. CVVHDF：支持 1:1 或自定义比例拆分置换液 / 透析液
6. 前稀释 / 后稀释作为独立配置
7. 前稀释暂提示有效清除差异，不在本阶段强行加入复杂校正
8. SCUF 不错误套用溶质清除剂量公式
9. 右侧实时显示计算结果
10. 正式构建配置为单个离线 HTML 文件，便于 U 盘带入医院内网电脑

产物：

- `src/calculators/fluid.ts`
- `docs/PHASE2-FLUID-CALCULATION.md`
- 实时结果摘要

## Phase 3：抗凝模块（已完成）

### 枸橼酸

已实现：

- 4% 枸橼酸钠按血流量换算初始泵速
- 可填写目标体外枸橼酸浓度；留空则显示 3–4 mmol/L 对应泵速范围
- 2026版指南滤器后 iCa 初始目标 0.2–0.3 mmol/L
- 肝功能衰竭、休克等枸橼酸蓄积高风险时提示 iCa 0.3–0.4 mmol/L
- 0.5% 枸橼酸盐置换液保留入口，但不误套 4% 枸橼酸泵速公式

### 普通肝素

已实现：

- 2023年中国专家共识 CRRT 首剂 5–15 IU/kg
- 维持 5–10 IU/kg/h
- 输入泵内浓度后自动换算 mL/h
- 显示 APTT / 抗 Xa 活性监测目标

产物：

- `src/calculators/anticoagulation.ts`
- `src/calculators/anticoagulation.test.ts`
- `docs/PHASE3-ANTICOAGULATION.md`

## Phase 4：电解质与缓冲液模块（已完成主流程）

### 葡萄糖酸钙

已实现：

- RCA 无钙处方液时：10% 葡萄糖酸钙初始速度 = 总流出液速度 ÷ 125
- 显示体内 iCa 目标 0.9–1.1 mmol/L
- 含钙处方液 + 前稀释 CVVH / CVVHD 的明确指南情景，显示 10% 葡萄糖酸钙初始 8 mL/h
- 2026版指南未明确覆盖的组合不外推固定值

### NaHCO₃（碳酸氢钠）

已实现：

- 基础处方液 HCO₃⁻ 浓度 + 医生设定目标浓度 + 需要补碱的基础液流量 → 补碱 mmol/h
- 根据 1.4%、5%、8.4% NaHCO₃ 自动换算 mL/h
- “其他”制剂可直接输入 mmol/mL
- RCA 时提示枸橼酸自身碱负荷及酸碱管理边界
- 不自动替医生选择目标 HCO₃⁻ 浓度

### KCl（氯化钾）

已实现：

- 基础处方液钾浓度 + 医生设定目标钾浓度 + 单袋体积 → 每袋需增加 K⁺ mmol
- 10%、15% KCl 自动换算 mL/袋
- “其他”制剂可直接输入 mmol/mL
- 高钾血症情景下按 2026 版指南检查目标处方液钾浓度是否在 0–2 mmol/L
- 若目标钾低于基础液钾浓度，提示改用更低钾 / 无钾基础液，不给负数加药量

产物：

- `src/calculators/electrolytes.ts`
- `src/calculators/electrolytes.test.ts`
- `docs/PHASE4-ELECTROLYTES-BUFFER.md`

## Phase 5：临床规则与校验层

新增 `src/validation/`：

- 必填字段检查
- 单位 / 数值范围检查
- 模式与液体字段的相容性检查
- 抗凝相关提示
- 结果异常提示
- 高风险组合与明显异常输入提醒

提示只做安全校验，不替代医生做适应证判断。

## Phase 6：结果页

输出结构：

- 患者基础参数
- 治疗模式
- 总治疗剂量
- 置换液速度
- 透析液速度
- 净超滤
- 抗凝剂量 / 速度
- 钙、NaHCO3、KCl 相关结果
- 计算依据 / 来源版本

支持：

- 一键复制文本
- 清空 / 重新计算
- 后续可扩展打印模板

## Phase 7：医学核对与来源管理

每条公式记录：

- 来源指南 / 共识
- 发布年份
- 页码 / 章节
- 公式或推荐范围
- 是否正式发布
- 最近核对日期

优先级：

1. 最新正式发布的中国 CRRT / 血液净化指南或共识
2. KDIGO 正式指南
3. 最新指南草案只作补充，不作为唯一正式依据

## 交付形态

开发源码继续保持模块化，方便维护；正式构建使用 `vite-plugin-singlefile`，将 React、CSS 和业务逻辑全部内联到：

```text
dist/index.html
```

医院电脑只需要这个文件，双击即可离线使用，不需要 Node.js、npm 或互联网。

## 开发原则

- 先跑通主流程，再补 1% 边缘情形
- UI、临床配置、公式、校验相互独立
- 新增常用选项优先改配置，不改页面骨架
- 所有“其他”分支必须可自由输入
- 所有计算值必须能追溯来源
- 计算器输出辅助参数，不自动替代临床判断
